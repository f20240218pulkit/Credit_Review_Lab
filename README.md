# Credit Review Lab

An SME credit analysis project built around financial statement spreading and evidence review.

- [Credit Review Lab v2](v2/README.md) includes PDF intake, source highlights, a persistent review workspace, replacement comparisons, stress scenarios and memo exports.
- [Static demo](index.html) is the original browser-only prototype.

The v2 documentation includes local, Docker and Vercel setup, a guided Meridian case, and evaluation results.
